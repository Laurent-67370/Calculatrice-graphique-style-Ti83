**Exemples :**

### Évaluateur d'Expressions

**Utilise mathjs :**
- Évaluation sécurisée
- Fonctions mathématiques complètes
- Remplacement des variables
- Gestion des erreurs

```typescript
static evaluateExpression(expr: string, context: ExecutionContext): number | string {
  // Remplacer les variables par leurs valeurs
  let processedExpr = expr;
  const varMatches = expr.match(/[A-Zθ]/g);
  if (varMatches) {
    for (const varName of varMatches) {
      const value = context.variables[varName];
      if (value !== undefined) {
        const regex = new RegExp(`\\b${varName}\\b`, 'g');
        processedExpr = processedExpr.replace(regex, value.toString());
      }
    }
  }
  return math.evaluate(processedExpr);
}
```

### Gestion des Boucles

**Stack de contextes :**
- ForLoopState[] : Boucles For
- WhileLoopState[] : Boucles While
- RepeatLoopState[] : Boucles Repeat

**Exécution :**
1. Empiler l'état au début
2. Exécuter le corps
3. Vérifier la condition à `End`
4. Dépiler ou revenir au début

### Appels de Sous-programmes

**Mécanisme :**
```typescript
// Empiler la frame
context.stack.push({
  programName: context.programName,
  returnLine: context.currentLine + 1,
  variables: { ...context.variables }
});

// Exécuter le sous-programme récursivement
await this.executeProgram(
  subProgramLines,
  subContext,
  onOutput,
  onClearScreen,
  onComplete,
  onError
);

// Mettre à jour les variables (globales)
context.variables = subContext.variables;
```
